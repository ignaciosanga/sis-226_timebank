# Criterios de Aceptación del Mockup

- Las cuatro pestañas principales son navegables.
- Inicio permite buscar y filtrar cursos.
- Inscribirse sin sesión abre el acceso institucional.
- Completar el acceso demostrativo añade el curso a Mis cursos.
- El calendario marca las fechas de las inscripciones.
- Perfil presenta carrera, intereses, cursos impartidos, puntos y valoración.
- Analíticas presenta métricas, actividad mensual y distribución por categoría.
- La interfaz se adapta a escritorio, tableta y celular.
- Los controles muestran foco visible y los elementos gráficos relevantes tienen etiquetas accesibles.
- La compilación de producción termina sin errores.
