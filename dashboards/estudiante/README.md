# Componentes Chart.js — Vista del Estudiante

Aquí se desarrollan los componentes de gráficos para la vista del estudiante, construidos con Chart.js (vue-chartjs).

## Componentes planificados

| Componente | HU | Descripción |
|------------|-----|-------------|
| Panel personal | HU01 | Tarjetas KPI de créditos + gráfico de servicios ofrecidos vs recibidos |
| Historial de movimientos | HU02 | Tabla de movimientos + gráfico de línea de evolución del saldo |
| Reporte de servicios | HU03 | Tabla de servicios + gráfico de barras por estado |
