# Recursos compartidos

Recursos visuales y de diseño compartidos por los dashboards del estudiante y del administrador.

## Paleta de colores sugerida

| Uso | Color | Hex |
|-----|-------|-----|
| Principal | Azul | `#3B82F6` |
| Éxito / Completado | Verde | `#22C55E` |
| Advertencia / Pendiente | Ámbar | `#F59E0B` |
| Error / Cancelado | Rojo | `#EF4444` |
| Información / En curso | Celeste | `#06B6D4` |
| Fondo oscuro | Gris | `#1E293B` |
| Texto principal | Blanco | `#F8FAFC` |

## Bocetos

Los bocetos de cada dashboard se agregarán aquí a medida que se diseñen.
